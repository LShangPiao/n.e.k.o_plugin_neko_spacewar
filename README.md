# 猫娘星海作战 / Neko Space War

<p align="center">
  <i>一款和猫娘并肩打的小游戏，由 <b>星河拓航Studio</b>（Galaxy Exploration Studio）开发与维护</i>
</p>

你驾驶一艘猫耳级星舰，在像素风的星海里一波一波清掉敌人。**身边那台僚机是她开的**，你喊一声「开盾」「集火」，她就照做；打得好她会夸你，打崩了她会先叹气再给你一句下次怎么打。

最特别的地方是：**游戏里跟你说话的那只猫娘，就是主界面上那只**——不是插件里另养的第二个角色，也不会另开一条模型会话。你在游戏里的通讯框打字，这句话会送到她那里；她回你的时候，同一句话会出现在游戏画面里。你不用在两个窗口之间来回看。

---

## 这游戏是什么样的

- **竖版弹幕射击**，鼠标拖着飞船跑，自动开火，不用背键位。
- **一局大概几分钟**，死得起，随时暂停（`P` / `Esc`）。
- **每 5 波来一艘母舰**，打掉有额外得分和羁绊；打完可以接着来下一局。
- **能长线玩**：有军衔、羁绊、徽章、历史最好成绩、出击与连胜记录，都存在本地。
- **开箱就能玩**：不需要另外装游戏，也不用下载素材——画面、音效全是插件自己用 Canvas 和 WebAudio 现画的。

## 她真的会说话

这不是「对话框里套一层模板」的假互动：

- **机内通讯** — 游戏右侧有个通讯栏，直接跟她说话，她当场回你，回话会显示在游戏画面里。
- **她会自己开口** — 开局、新一波、母舰出现、母舰被击破、装甲告急、连击冲到 20 或 50、本局结束，这七个时刻会触发她**主动**跟你说一句，而不是等你问。
- **她看得到真实战况** — 每次开口前，游戏会把真实数据同步给她：第几波、得分、装甲、羁绊、击毁多少架、被打中几次、连击、火力等级、场上还剩几架敌机、母舰还有多少血、这局打了多久。
- **她不会乱编** — 数据里没有的东西（你刚才是躲了还是在输出）她会直接说不知道。打得好她会夸，打崩了她会先安慰再建议。
- **你也能在聊天里指挥她** — 在主界面跟她说「开个护盾」「集火那个坦克」「放星爆」，指令会排进游戏里执行。

> 想让她换个称呼？把设置里的 `wingman_name` 改成你自己猫娘的名字就行。只影响游戏画面里的标签，说话的一直是她本人。

## 怎么玩

| 操作 | 怎么按 |
| --- | --- |
| 移动 | 拖动鼠标，或 `WASD` / 方向键 |
| 开火 | 自动，不用按 |
| 暂停 | `P` 或 `Esc` |
| 战术指令 | 数字键 `1`–`4`，或点屏幕上的按钮 |

**四个战术指令**（花羁绊，都有冷却）：

| 键 | 指令 | 效果 | 消耗 / 冷却 |
| --- | --- | --- | --- |
| `1` | 护盾展开 | 2.2 秒无敌，顺手清掉身边的弹幕 | 32 羁绊 / 24 s |
| `2` | 集火指令 | 僚机对最强目标连续激光 3.5 秒 | 38 / 28 s |
| `3` | 紧急维修 | 恢复 1 点装甲（上限 5 点） | 55 / 40 s |
| `4` | 猫猫星爆 | 2.2 秒全屏光束，清弹并重创全场 | 95 / 75 s |

**羁绊**是资源，也是你俩的亲密度：击毁一架 +1、清空一波 +5、打掉母舰 +12、捡到 `B` 补给 +10、让她打气 +2（同一场 15 秒只能打一次气）。被击中会掉。

**补给**会从敌人身上掉：`P` 火力增强、`A` 装甲修复、`B` 羁绊补充。坦克掉得多一些，杂兵掉得少。

## 难度会越来越凶

三条基础难度（轻松 / 普通 / 硬核）打底，波数再往上叠：

| 越来越…… | 每波涨多少 | 封顶 |
| --- | --- | --- |
| 敌人更耐打 | 生命 +7% | — |
| 弹幕更密 | 出弹频率 +3.5% | 2.4 倍 |
| 子弹更快 | 弹速 +1.5% | 1.45 倍 |
| 场上更满 | 每波敌机 6 + 波数 × 2.4 架 | 48 架 |

另外：母舰血量 `80 + 波数 × 34`；第 12 波起炮艇开始双发，第 15 波起母舰四连发；环弹和召唤的小怪数量也随波数往上涨。

前几波是热身，二十波往后就开始手忙脚乱了——这就是为什么她的护盾和星爆都有冷却、都要花羁绊：她帮你，但没到「有她在就输不了」的程度。

## 一局结束之后

战报会送到主界面，让她点评你这一局：打得好她夸你，打得难看她会先安慰再给一句下次怎么打更稳的建议。羁绊攒够了会解锁徽章，军衔和历史最好成绩也会一直往上走。

## 开始玩

1. 在 N.E.K.O. 的插件列表里启用「猫娘星海作战」，点开它的页面就能玩，不需要安装任何游戏。
2. 让主界面的猫娘在线，机内通讯和主动搭话才会开口；她不在的时候游戏照样能玩，只是安静一点。
3. 首次打开会给你「普通」难度和自动开火，觉得太温柔可以在游戏设置里换「硬核」。

**不想让她说话？** 设置里有两个开关可以单独关掉：`llm_chat_enabled`（机内通讯）和 `llm_banter_enabled`（主动搭话）。

## 常见问题

**她说的话好像不太符合战况？**
每条消息都带着真实数据（击毁、被打中次数、剩余敌机、母舰血量），她只能照着这些说。如果她说了数据里没有的东西，那属于模型发挥，可以当成她在瞎猜。

**可以完全不用她、自己硬打吗？**
可以。关掉两个说话开关，再把难度切到「硬核」，就是纯单人弹幕游戏；战术指令也能全部自己按。

**存档会丢吗？**
档案存在插件自己的本地数据库里，不上传。清空战绩用设置里的重置（保留设置项）。

**会不会联网、会不会把我玩的数据传出去？**
不会。游戏是插件自带的静态页面，全部在本地跑；说话走的是你已经配置好的 N.E.K.O. 模型，插件自己不持有任何密钥、也不直连任何外部服务。
